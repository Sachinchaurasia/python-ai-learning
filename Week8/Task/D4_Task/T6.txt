Here's what happens at each stage:

Text → Original human-readable text.
Tokenization → Breaks text into tokens.
Tokens → Individual pieces of text.
Token IDs → Each token gets a numerical identifier.
Embeddings → Token IDs are converted into learned vectors of numbers.
Transformer → Processes those vectors using mechanisms such as attention to understand relationships and context.
