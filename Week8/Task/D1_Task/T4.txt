# TASK 4 — Prompt → Model → Generated Output

# This flow shows how Generative AI produces an answer.

# Prompt
#   ↓
# Model
#   ↓
# Generated Output
# 1️⃣ Prompt

# A prompt is the instruction or question that we give to the AI model.

# Example:

# "Write a Python program to calculate the factorial of a number."
# 2️⃣ Model

# The model is the trained AI system that understands the prompt and predicts what content should come next based on patterns it learned during training.

# For example, an LLM can understand that the user is asking for Python code.

# 3️⃣ Generated Output

# The model produces a response based on the prompt.

# For example:

# def factorial(n):
#     if n == 0:
#         return 1
#     return n * factorial(n - 1)
# 🧠 Simple analogy

# Think of it like asking a skilled programmer:

# Your Question
#      ↓
# Programmer thinks about it
#      ↓
# Programmer gives you an answer

# In Generative AI:

# Prompt
#   ↓
# AI Model
#   ↓
# Generated Content
# ⭐ In one sentence

# A prompt is the input/instruction, the model processes and interprets that input, and the generated output is the new content produced by the model.
