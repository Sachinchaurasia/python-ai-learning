🧠 Remember the flow
Text
  ↓
Tokenization       → Break text into tokens
  ↓
Token IDs          → Convert tokens into numbers
  ↓
Embeddings         → Convert IDs into meaningful vectors
  ↓
Positional Info    → Tell the model token order
  ↓
Self-Attention     → Understand relationships between tokens
  ↓
Feed-Forward       → Further process the information
  ↓
Output

🔥 Key connection: This pipeline is the foundation for understanding how an LLM processes text inside a Transformer.
